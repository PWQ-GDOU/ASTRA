# 火箭喷管喉部侵蚀／烧蚀 RUL 公共数据审计

**审计日期：2026-07-24**

## 1. 结论摘要

截至 **2026-07-24**，在本审计所核验的 DOI 注册元数据、出版商记录、机构知识库记录及公开附件说明中，**未发现已经核验为可下载、机器可读，并且与“火箭喷管喉部侵蚀／烧蚀剩余使用寿命（RUL）预测”同任务的公共原始数据集**。

这里的“未发现”是有范围限定的审计结论，不是对互联网上绝对不存在此类数据的证明。现有候选主要属于以下几类：

1. 与喷管侵蚀／烧蚀直接相关的论文或学位论文，但公开附件只有 PDF；
2. 被仓储标为“Dataset”的论文补充记录，但本次未能核验到可直接用于建模的逐试验、逐时刻原始数值文件；
3. 同域数值模拟动画或图像，而不是带寿命标签的表格时序；
4. 材料试样的等离子烧蚀试验，与实际火箭喷管喉部运行轨迹和 RUL 任务不等价。

因此，这些资料可以作为**机理、实验设计、数量级或模型验证线索**，但不能据此声称当前工作使用了“公共同域 RUL 数据集”，也不能把从论文图表人工读出的点称为公开原始数据。

## 2. 判定口径与核验方法

### 2.1 “同域、同任务、可用数据集”的最低条件

本审计同时要求以下条件：

- **同域**：对象是火箭发动机喷管，重点为喉部或其邻近区域的热化学烧蚀、氧化侵蚀、颗粒侵蚀及几何退蚀；
- **同任务**：存在多个可区分的试验／发动机／工况轨迹，且具有随时间或循环演化的退蚀观测和明确失效阈值，能够直接提供或无歧义地构造 RUL；
- **机器可读**：原始或经说明的数值文件为 CSV、TSV、JSON、HDF5、NetCDF、MAT、Parquet 等；PDF、扫描表格、曲线图片和动画本身不满足此项；
- **可下载且可复核**：能够确认具体文件、版本和下载入口，而不是只看到论文摘要、仓储题名或“有补充材料”的提示；
- **来源与权利清楚**：至少能够识别数据拥有者、出处、版本和适用于具体文件的许可／使用条件。仓储集合页与集合内单项的许可不同，应以实际下载单项的权利声明为准。

仅有燃烧前／后两个几何测量值，可以支持端点侵蚀或平均侵蚀速率研究，但通常不足以形成严格的时序 RUL 基准；只有一条模拟轨迹，也不足以检验跨发动机或跨工况的泛化 RUL。

### 2.2 本次核验边界

本次逐项核验了用户指定 DOI 的规范解析结果，以及可取得的 DataCite、Crossref、NASA NTRS、机构知识库和出版商元数据。对文件清单或文件本体无法可靠取得的记录，统一标为“未核验”，不根据仓储类型、网页按钮或搜索摘要推定文件格式与内容，也不推定许可。

### 3.1 审计结论的强度

上述五组候选足以证明该领域存在相关试验、模型和可视化资料，却不足以证明存在可直接复用的公共同任务训练／测试集。特别应避免下列推断：

- 仓储把对象标为 `Dataset`，不等于附件必然包含机器可读原始观测；
- DOI 可解析或网页有“Download”，不等于已核验文件内容、许可和完整性；
- 论文给出若干曲线，不等于存在可重复划分的多试验 RUL 数据；
- 数值动画能显示退蚀，不等于有可用于公平比较的时空数值场；
- 单次点火的最终喉径或平均侵蚀速率，不等价于 RUL 标签。

## 4. 明确排除的近邻数据

### 4.1 NASA C-MAPSS

**C-MAPSS 必须从“同域数据”中明确排除。** 它描述航空燃气涡扇发动机的模拟退化与失效过程，其系统对象、退化机理、传感器语义、运行循环和失效定义均不是火箭喷管喉部热化学侵蚀／烧蚀。将其称为“火箭喷管同域基准”会造成事实错误。

C-MAPSS 可以保留为**跨域方法证据**，例如用于说明 run-to-failure 划分、按发动机单元防止数据泄漏、RUL 截断、归一化及 RMSE／MAE／评分函数的常见做法。但任何 C-MAPSS 上的性能都不能替代火箭喷管数据上的外部验证，也不能证明模型掌握了喷管烧蚀机理。

### 4.2 涡轮与喷管图像数据集

以下类别同样不纳入本任务的数据规模或同域基准统计：

- 燃气轮机叶片、导向叶片或航空发动机热端缺陷图像；
- 工业喷嘴／喷管表面裂纹、积碳、堵塞或磨损图像；
- 喷管烧蚀后的显微、SEM、X 射线、温度云图和单次剖面图片；
- CFD 云图截图或退蚀动画。

这些资源可用于视觉缺陷检测、材料表征或定性验证，但通常缺少火箭喷管喉部的连续运行条件、统一空间标定、时间戳、失效阈值和剩余寿命标签。除非公开了同一喷管从健康到阈值的纵向、标定图像序列，并能与工况和几何测量一一对应，否则不得把它们表述为本任务的 RUL 数据集。

## 6. 为什么当前 CSV 不能公平地计算 Bartz 数值基线

当前文件 `data/raw/nozzle_ablation_full.csv` 有 **56 行、13 列**，表现为一条从 0.0001 s 到 20 s 的轨迹。可见字段包括累计时间、喉部流体／固体温度、喉部压力、内壁热流、最大烧蚀速度、累计／目标烧蚀深度及网格质量。目标烧蚀深度固定为 0.2585 mm，喉部流体温度约为 1147 K，喉部压力约为 1.43 MPa；CSV 自身没有提供来源说明、试验／仿真 ID、单位定义文档或不确定度。

标准 Bartz 计算通常至少涉及或依赖：

- 喉径或局部直径、喉面积、局部面积比和喉部曲率半径；
- 燃烧室总压，而非语义未说明的“喉部压力”；
- 特征速度 `c*` 或等价质量流率／质量通量信息；
- 燃气定压比热、黏度、Prandtl 数、比热比及其评价温度；
- 燃烧室总温、局部 Mach 数、恢复因子或绝热壁温；
- 明确的壁面表面温度位置，以及是否采用 Bartz 的温度／物性修正因子；
- 推进剂／氧化剂组成和混合比，以确定燃气物性及反应性组分；
- 若要从热流继续预测烧蚀，还需要材料密度、热导率、比热、发射率、热解／氧化动力学、烧蚀焓和表面反应边界条件。

当前 CSV 缺少上述几何、质量流、燃气组成与物性、总状态和材料参数。`喉部流体温度_K` 不一定等于燃烧室总温或绝热壁温，`喉部固体温度_K` 也未说明是否为气固界面的表面温度。直接把 CSV 已有的 `内壁热流_W_m2` 反推缺失系数，再把同一热流作为 Bartz 预测值，会形成**目标泄漏／循环验证**；用未经记录的典型值补齐参数，则会把参数选择误差混入模型误差。

因此，当前阶段可以做的只有：

1. 把已记录热流、温度和退蚀速率做内部一致性与量纲检查；
2. 在明确标注假设和敏感性区间的前提下，做非评分性质的 Bartz 数量级演示；
3. 等几何、工况和物性补齐后，再冻结 Bartz 实现并计算独立数值基线。

在缺参补齐之前，**不应报告“Bartz 优于／劣于某学习模型”的定量结论**，也不应把 Bartz 由同一 CSV 反演校准后的误差称为外部物理基线。

## 7. 可直接用于报告的稳健表述

建议采用：

> 截至 2026-07-24，我们未在已核验的公开来源中发现可直接下载、机器可读且与火箭喷管喉部侵蚀／烧蚀 RUL 同任务的原始数据集。已识别资料主要是论文 PDF、材料试样研究或数值可视化，可用于机理与数量级参照，但不足以构成公共同域 RUL 基准。

> C-MAPSS 仅用于跨域算法流程或评价协议的参考，不被视为火箭喷管同域数据，也不作为喷管物理有效性的证据。

> 在来源、生成流程和验证记录补齐之前，本文将 `nozzle_ablation_full.csv` 称为“当前项目喷管退蚀时序 CSV”，不将其表述为公共实验数据、真实发动机 run-to-failure 数据或独立外部验证集。

> Bartz 关联及 Cross–Boyd 模型作为方法学参照。由于当前 CSV 缺少喷管几何、质量流／特征速度、燃气物性、总状态和材料响应参数，本研究暂不报告可与学习模型公平比较的 Bartz 数值分数。

应避免采用：

- “我们使用了公开火箭喷管 RUL 数据集”；
- “Figshare 已提供完整原始数据”（除非实际文件已经下载和逐项核验）；
- “C-MAPSS 是同域喷管数据”；
- “论文曲线数字化结果就是原始实验数据”；
- “当前 CSV 已被 Bartz 完整验证”；
- “open access 等于可任意再分发数据”。

## 8. 数据获取清单

如果继续向作者或机构申请数据，最低应索取并核验：

### 8.1 文件与试验结构

- [ ] 原始文件为 CSV／HDF5／MAT 等机器可读格式，并附字段字典；
- [ ] 每次点火／每台发动机有稳定唯一的 `motor_id`、`test_id`、`nozzle_id`；
- [ ] 原始、校准、派生数据分层保存，派生公式可追溯；
- [ ] 时间基准、采样率、同步方式、缺测／饱和／异常标志明确；
- [ ] 提供重复试验和失败／中止／删失试验，而非只提供“最佳一次”；
- [ ] 文件版本、DOI／仓储记录、获取日期和 SHA-256 校验值可记录。

### 8.2 几何、材料与工况

- [ ] 初始喷管轮廓、喉径、喉部曲率半径、面积比和测量坐标系；
- [ ] 材料牌号、批次、密度、孔隙率、纤维方向，以及温度相关的 `k`、`cp`、发射率等；
- [ ] 推进剂／燃料／氧化剂组成、配比、O/F、质量流率及其不确定度；
- [ ] 燃烧室总压／总温、局部压力／温度的测点位置和传感器校准；
- [ ] 气体物性或可复算物性的化学平衡输入；
- [ ] 颗粒尺寸／负载、冷却方式、环境条件和点火／关机瞬态说明。

### 8.3 退蚀与 RUL 真值

- [ ] 喉径或壁面退蚀量具有随时间／循环的观测，而不只是前后两个端点；
- [ ] 测量方法（CMM、轮廓仪、CT、原位成像等）、空间分辨率和不确定度明确；
- [ ] 明确定义失效阈值：最大允许喉径增量、深度、推力／压强偏差或结构极限；
- [ ] RUL 的时间单位、预测起点、删失规则和阈值穿越插值规则预先固定；
- [ ] 若只有端点数据，则降级命名为“端点侵蚀／平均速率数据”，不包装成时序 RUL；
- [ ] 仿真数据与实测数据有明确标记，并给出仿真验证误差和参数来源。

### 8.4 许可和合规

- [ ] 取得适用于**具体数据文件及其版本**的许可证或书面使用授权；
- [ ] 区分论文许可、仓储集合许可、子项许可和文件内嵌许可；
- [ ] 确认是否允许修改、机器学习训练、商业使用和再分发；
- [ ] 记录署名、引用、通知作者及共享派生数据的义务；
- [ ] 对“版权及其他限制可能适用”或无许可记录，不推定可再发布；
- [ ] 若存在保密、出口管制、第三方权利或设施数据限制，先取得负责机构书面确认。

## 9. 对外发布／基准发布清单

- [ ] 发布数据卡：来源、生成／采集流程、适用范围、已知偏差和禁止用途；
- [ ] 原始数据只读保存；清洗脚本从原始文件可重复生成发布版本；
- [ ] 单位统一为 SI，并保留原单位、转换公式和有效数字；
- [ ] 明确每列是测量值、边界条件、仿真输出、派生标签还是质量控制字段；
- [ ] 按 `motor_id`／`test_id` 划分训练、验证和测试集，禁止把同一轨迹的相邻行随机拆到不同集合；
- [ ] 在看测试集前冻结失效阈值、RUL 构造、归一化和评价代码；
- [ ] 同时报告 MAE、RMSE、分工况结果、置信区间和删失处理，不只报告单一最优分数；
- [ ] 提供简单时间／线性退蚀、经验速率和可复现物理模型基线；物理基线缺参时明确标记“不可计算”，不静默填值；
- [ ] 记录传感器、几何和材料不确定度，并做参数敏感性／分布外工况检验；
- [ ] 单独保留真实试验外部验证集；仿真行数不能被表述为独立真实样本数；
- [ ] 发布确切许可证文本、推荐引用、版本号、变更日志、文件哈希和长期存档 DOI；
- [ ] 在发布说明中再次声明：C-MAPSS 与涡轮／喷管图像仅是跨域或辅助证据，不计作火箭喷管同域 RUL 数据。
