# PINN 极端段特征工程

## 特征设计目标

为物理信息神经网络（PINN）退化预测模型提取 GEO 卫星电池在阴影期**极端段**的物理特征，实现高精度 SOH 估计与剩余寿命预测。

## 完整特征列表

### 一、时域特征 (Temporal Features)

| 特征 | 参数名 | 描述 |
|------|--------|------|
| 地影时长 | `shadow_min` | GEO 阴影持续时间 (5-72 min) |
| 年份时序 | `F_year` | 循环次数/总循环的正则化 |
| 季节时序 | `F_season` | 轨道相位特征 |

### 二、工况特征 (Operating Features)

| 特征 | 参数名 | 描述 |
|------|--------|------|
| DOD 特征 | `F_DOD` | 放电深度 (0.8 × shadow/72) |
| 退化应力 | `stress` | 综合退化应力 σ |
| 放电电流 | `Idis` | 0.667C × Qnom |

### 三、电压降特征（极端段核心特征）

| 特征 | 参数名 | 描述 |
|------|--------|------|
| 30秒电压降 | `dV30` | 放电开始 30s 后电压降 |
| 60秒电压降 | `dV60` | 放电开始 60s 后电压降 |
| 90秒电压降 | `dV90` | 放电开始 90s 后电压降 |
| 120秒电压降 | `dV120` | 放电开始 120s 后电压降 |

### 四、曲线熵特征（电压曲线形态）

| 特征 | 参数名 | 描述 |
|------|--------|------|
| 30秒曲线熵 | `E30` | 0-30s 电压曲线信息熵 |
| 60秒曲线熵 | `E60` | 0-60s 电压曲线信息熵 |
| 90秒曲线熵 | `E90` | 0-90s 电压曲线信息熵 |
| 120秒曲线熵 | `E120` | 0-120s 电压曲线信息熵 |

### 五、退化状态特征

| 特征 | 参数名 | 描述 |
|------|--------|------|
| SOH | `soh` | 健康状态 (0-1) |
| 容量 | `capacity_mAh` | 当前容量 [mAh] |

## 特征物理意义

### 电压降特征 → 内阻映射

电压降 $Delta V$ 主要反映电池欧姆内阻和极化内阻：

$$
\Delta V(t) \propto r_{\text{int}} \cdot I_{\text{dis}}
$$

随着电池退化，内阻增大 → 电压降增大 → **直接关联 SOH**

### 曲线熵 → 电化学退化

电压降曲线的熵值反映电池内部电化学过程的**不均匀性**：
- 新电池: 曲线平滑，熵低
- 退化电池: 多时间常数响应，熵高

## PINN 训练数据格式

每行含 19 个特征：
```
[time, SOH, capacity, rint, tcell, Tavg, shadow_min, F_DOD, F_year, F_season, dV30, dV60, dV90, dV120, E30, E60, E90, E120, stress, RUL]
```

数据输出见 `GEO卫星电池PINN极端段特征输出.csv`（1200行，时间步长 1s）
