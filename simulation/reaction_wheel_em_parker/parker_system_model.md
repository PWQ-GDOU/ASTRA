# 帕克对齐系统级 ODE 退化模型

## 模型描述

反作用轮无刷直流电机系统级退化预测全局常微分方程模型。参考帕克等人在《空间研究进展》2023 年第 71 卷第 6 期论文的系统级预测思想。当前版本加入相电流一阶动态、绕组集总热动态、温度反馈电阻、非线性摩擦退化和等效齿槽/振动遥测。定量使用前必须用论文、厂家或实测数据替换待填默认参数。

参考 Parker 等人在《空间研究进展》2023 年第 71 卷第 6 期论文的系统级预测思想。

### 物理场接口
- **全局常微分方程 (GlobalEquations)**: 无刷直流电机电-机-热退化模型

### 状态变量
| 变量 | 含义 | 单位 |
|------|------|------|
| `theta` | 转子机械角位置 | rad |
| `omega` | 转子机械角速度 | rad/s |
| `curA` | A 相电流 | A |
| `curB` | B 相电流 | A |
| `curC` | C 相电流 | A |
| `Twind` | 绕组温度 | °C |

### 控制策略
- 等效 PWM 速度环比例控制
- 速度指令: 4000 rpm (418.879 rad/s)
- 比例增益: Kp = 0.018
- 占空比: duty = sat(0.40 + Kp × (ω_cmd - ω), 0, 1)

### 模型特性
- ✅ 已求解（含完整时域结果）
- 相电流一阶动态
- 绕组集总热动态 + 温度反馈电阻
- 非线性摩擦退化 (γ^1.7 幂律)
- 等效齿槽/振动遥测
