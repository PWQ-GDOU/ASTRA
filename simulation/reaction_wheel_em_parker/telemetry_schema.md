# 时域遥测数据格式

## 数据来源
`反作用轮多物理场后处理时域遥测.csv`

## 时间设置
- 总仿真时长: 0.35 秒
- 时间步长: 1 ms
- 数据行数: 351 行 (含标题)

## 字段说明

| 列索引 | 字段名 | 单位 | 描述 |
|--------|--------|------|------|
| 1 | 时间 | s | 仿真时间 (0 → 0.35s) |
| 2 | 转角 | rad | 转子机械角位置 |
| 3 | 角速度 | rad/s | 转子机械角速度 |
| 4 | 角速度 | rpm | 转子转速 |
| 5 | 甲相电流 | A | A 相电流 |
| 6 | 乙相电流 | A | B 相电流 |
| 7 | 丙相电流 | A | C 相电流 |
| 8 | 甲相电压 | V | A 相端电压 |
| 9 | 乙相电压 | V | B 相端电压 |
| 10 | 丙相电压 | V | C 相端电压 |
| 11 | 直流母线电流 | A | DC bus 电流 |
| 12 | 电磁转矩 | N·m | 电磁转矩 |
| 13 | 齿槽转矩 | N·m | 齿槽/脉动转矩 |
| 14 | 摩擦转矩 | N·m | 总摩擦力矩 |
| 15 | 绕组温度 | °C | 绕组平均温度 |
| 16 | 铜耗功率 | W | 绕组焦耳热功率 |
| 17 | 摩擦功率 | W | 摩擦功耗 |
| 18 | 振动加速度 | m/s² | 轴承振动加速度遥测 |
| 19 | 退化程度 | - | 归一化退化等级 γ |
| 20 | 磨损摩擦 | N·m | 附加磨损摩擦力矩 |
| 21 | 电阻下降比例 | - | 匝间短路电阻变化 dR |
| 22 | 剩磁衰减比例 | - | 永磁体退磁比例 dBr |
| 23 | 剩磁比例 | - | Br/Br0 比值 |
| 24 | 相电阻 | Ω | 实际相电阻 R_phase |
| 25 | 相电感 | H | 实际相电感 L_phase |
| 26 | 剩余寿命比例 | - | RUL 归一化 (1=健康) |

## 关键遥测特征（退化检测用）
- **电流特征**: 相电流幅值/谐波随退磁和匝间短路变化
- **转矩特征**: T_em 均值下降，T_cog 脉动增大
- **温度特征**: T_wind 因电阻增大/duty 升高而上升
- **振动特征**: a_vib 随 γ 增大而增大（二次型）
