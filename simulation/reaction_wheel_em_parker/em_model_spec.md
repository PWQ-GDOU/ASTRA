# 二维实体电磁模型规格

## 模型架构

**物理场**: 感应电流 (InductionCurrents, 磁场接口)
**维度**: 2D 轴对称 (Az 分量)
**单位制**: SI (国际单位制)
**频率**: 从求解器自动确定

### 几何结构（从内到外）
| 组件 | 几何特征 | 材料 |
|------|---------|------|
| 转子铁芯 | 内圆 | 软铁 (Soft Iron) |
| 永磁体 | 圆环 (4极对) | NdFeB (Br=1.2T) |
| 气隙 | 环形差集 | 空气 (非固体) |
| 定子绕组 | 环形槽 | 铜 (Copper) |
| 定子铁芯 | 外圆 | 软铁 (Soft Iron) |

### 控制方程（磁场）
矢量磁位 $mathbf{A}$ 满足:

$$
\nabla \times \left(\frac{1}{\mu} \nabla \times \mathbf{A}\right) + \sigma \frac{\partial \mathbf{A}}{\partial t} = \mathbf{J}_e + \nabla \times \mathbf{H}_c
$$

其中:
- $mu$ — 磁导率
- $sigma$ — 电导率
- $mathbf{J}_e$ — 外部电流密度
- $mathbf{H}_c$ — 永磁体矫顽力

### 本构关系
- **自由空间**: 相对磁导率 + 电导率 + 介电常数
- **软铁**: B-H 曲线 (非线性磁导率)
- **永磁体**: 剩余磁通密度 Br = 1.2T × (1 - 0.4γ)
- **铜绕组**: 电导率 5.998e7 S/m

### 退化参数 γ
- γ = 0: 健康状态
- γ = 1: 完全失效
- 影响: 永磁体退磁、匝间短路、轴承磨损
