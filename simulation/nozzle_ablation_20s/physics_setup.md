# 物理场设置

## 物理场接口列表

- **论文压力曲线约束SST湍流反应流接口** (`ReactingFlowSST`, tag: `rfsst`)
- **C/C喉衬固体瞬态传热** (`HeatTransfer`, tag: `ht`)
- **五组分烧蚀退化ALE动网格** (`MovingMesh`, tag: `ale`)

## 1. 湍流反应流 (ReactingFlowSST)

### 湍流模型
- **模型**: SST k-ω
- **可压缩流动**: 是
- **维度**: 2D 轴对称

### 多组分输运
| 组分 | 摩尔分数 | 入口质量分数 |
|------|---------|-------------|
| OH   | 3.0%    | 0.030       |
| O    | 2.0%    | 0.020       |
| H₂O  | 48.0%   | 0.480       |
| CO₂  | 18.0%   | 0.180       |
| O₂   | 29.0%   | 0.290       |

### 气体属性
- 气体常数: Rs = 287 J/(kg·K)
- 定压比热: Cp = 2600 J/(kg·K)
- 比热比: γ = 1.22
- 动力黏度: μ = 4×10⁻⁵ Pa·s
- 导热系数: k = 0.12 W/(m·K)
- 普朗特数: Pr = 0.72

## 2. 固体传热
- **区域**: C/C 复合材料喉衬
- **密度**: ρ = 1800 kg/m³
- **外壁对流**: h = 15 W/(m²·K), T∞ = 300 K

## 3. 移动网格 (ALE) — 烧蚀边界
通过 ALE 实现内壁面因烧蚀而后退：
- 烧蚀速率上限: 0.10 mm/s（单步稳定限制）
- 目标烧蚀量: Δr = 0.2585 mm（20秒喉部半径增量）
- 烧蚀缩放因子: 346.0（五组分校准）
